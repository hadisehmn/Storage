# GoStorage

GoStorage is a file storage backend written in Go.

This project is built to learn Go by implementing a file storage service.
The application will receive files from clients, store them, and provide APIs to manage stored files.


## Learning Goals

- Go
- HTTP servers
- File handling
- REST APIs
- Docker
- Monitoring
- Server deployment


## Planned Features

- Upload a file
- Download a file
- Delete a file
- Get file information
- Run with Docker
- Monitor the application
- Deploy to a server
